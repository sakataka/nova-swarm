# Nova Swarm

レトロアーケード調のブラウザ向けシューティングゲームです。Space Invaders や Galaxian 風の編隊・急降下アクションをベースに、5面構成、敵バリエーション、ボム、ボス戦、チップチューン風BGM/効果音を入れています。

## 起動方法

```bash
bun install
bun run dev
```

表示されたローカルURLをブラウザで開きます。通常は以下のようなURLです。

```text
http://127.0.0.1:5173/
```

## 公開URL

GitHub Pages で公開する場合のURLです。

```text
https://sakataka.github.io/nova-swarm/
```

## 操作方法

| 操作 | キー |
| --- | --- |
| 移動 | `A` / `D` または `←` / `→` |
| ショット | `Space` |
| ボム | `Shift` または `B` |
| ポーズ | `P` |
| ミュート | `M` |
| 開始 / リスタート | `Enter` |

## ゲーム内容

- 全5ステージ構成
- 通常敵は1発で撃破
- 敵は編隊移動、急降下、蛇行、弾幕などのパターンを持つ
- ボムは画面内の通常敵と敵弾を一掃し、ボスにもダメージを与える
- 5面は大型ボス戦で、HPバーと攻撃フェーズがある
- スコア、ステージ、残機、ボム数は画面上部HUDに表示

## アセット

画像アセットはAI生成したピクセルアートを使用しています。

- `public/assets/spritesheet.png`: 自機、敵、弾、爆発、ボスなどの固定グリッドスプライト
- `public/assets/backgrounds.png`: 5ステージ分の宇宙背景アトラス

スプライトは `4x4` の固定セルとして切り出す設計です。切り抜きズレを避けるため、コード側ではセル座標からアトラス位置を計算しています。

## 開発コマンド

```bash
bun run dev      # 開発サーバー
bun run build    # TypeScript + Vite の本番ビルド
bun run preview  # ビルド結果のプレビュー
```

## テスト用URL

開発中の確認用に、URLパラメータで直接ゲーム開始やステージ指定ができます。

```text
/?autostart=1
/?autostart=1&stage=5
```
